## Featured project

### [Projeto Semantrix: The Inventory Dilemma](https://github.com/EnzoTorres3023/Projeto-Semantix)

Final project of the EBAC Data Analytics course, in partnership with Semantrix. Analysis of 100k+ orders from Brazilian e-commerce (Olist dataset) to reduce overstock and stockouts.

- **Data collection:** Olist dataset via Kaggle API and Google Trends series via pytrends
- **Preparation:** cleaning and feature engineering in Python (Pandas)
- **Analysis:** ABC curve by revenue and the link between delivery time and customer rating
- **Dashboard:** [interactive report in Looker Studio](https://lookerstudio.google.com/reporting/dc4b7bef-6064-4ce7-b679-fa42c132f3ee)
